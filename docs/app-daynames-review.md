# TubeTrainer — built-in workout/day names, for review

_These are the app's **default seeded workout names** (the "Push Day / Pull Day / Leg Day"
style titles a user sees before renaming anything). Everything else in the app was already
reviewed; these are the only new strings. Please critique the Spanish, Portuguese (BR) and
German for a gym audience in one pass._

Notes:
- We deliberately kept the *split-picker* name **"Push / Pull / Legs"** in English (your earlier
  advice). These are the individual **day** names, which we did translate.
- Chest / Back / Shoulders reuse the already-approved muscle-group terms.
- User-renamed workouts are never translated — only these built-in defaults.
